Rangkuman Edukasi: Logika Debugging

Mengapa sebuah kode bisa mogok (stall) seperti mesin yang rusak? Berikut adalah dasar-dasar kesalahan kode (bug) di Informatika:

  • Infinite Loop:
  • Assignment (=) vs Comparison (==): Kesalahan sintaks umum. Tanda samadengan tunggal (=) digunakan untuk memberi nilai variabel, sedangkan ganda (==) digunakan untuk membandingkan kondisi di dalam if-statement.
  • Null Reference (DOM Error): Dalam Pemrograman Web I, JavaScript sering berjalan sebelum elemen HTML selesai dimuat. Ini menyebabkan variabel bernilai *null*. Gunakan atribut `defer` atau letakkan script di akhir body.
  • Pit Stop Mentality: Debugger yang baik tidak asal menebar `console.log()`. Ia membaca pesan error, melacak baris error, dan membedah akar masalah. Ini adalah skill fundamental seorang arsitek kode.
