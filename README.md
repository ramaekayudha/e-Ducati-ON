# 🚀 Fitur Utama
## Cinematic Hero Reel: Dark mode estetik hardcore dengan auto-slideshow B&W dan slow statistics counter.
## Readiness Assessment Engine: Mesin prediksi 20 soal (diacak menjadi 5 soal) berbasis JavaScript dengan tombol Regenerate 1x.
## The Matrix (KRS Blueprint): Tabel dinamis yang merender data KRS asli (Semester 1, 19 SKS).
## Future KRS Planner: Form input untuk menambahkan mata kuliah semester depan secara real-time (DOM Manipulation).
## IPK Target Simulator: Kalkulator matematis real-time yang terkunci pada SKS yang sudah diambil (status: Taken).
## Humanist Aesthetics Section: Integrasi nilai estetika dan humanisme di tengah algoritma dingin.
## Enterprise Media Hub: Video, audio, dan galeri sinematik lokal dengan efek hover grayscale-to-color.
## 3D Contributor Cards: Interaktivitas hover rotateY CSS lengkap dengan foto profil (atau avatar otomatis) dan tautan media sosial.

# 🛠️ Teknologi yang Digunakan
## HTML5 Semantik: Paragraf, heading, text formatting, link, image, table, list, form, video, audio.
## Custom CSS3: Tanpa framework eksternal. Menggunakan Flexbox, CSS Grid, 3D Transforms, Backdrop Filter, dan CSS Variables.
## Vanilla JavaScript (ES6): Array of Objects (In-Memory Database), IntersectionObserver, DOM Manipulation, Math Randomization, dan Event Listeners.
