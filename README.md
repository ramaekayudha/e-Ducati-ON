🚀 Fitur Utama
Ignition Sequence Preloader: Animasi booting terminal saat website pertama kali dimuat.
Cinematic Hero Reel: Latar belakang slider hitam-pekat dengan tipografi raksasa High-Performance Logic.
Informatika Readiness Assessment: Mesin prediksi 20 soal (diacak menjadi 5 soal) berbasis JavaScript dengan tombol Regenerate 1x.
The Matrix (KRS Blueprint): Tabel dinamis yang merender data KRS asli (Semester 1, 19 SKS) berdasarkan status Taken/Planned.
Future KRS Planner: Form input untuk menambahkan mata kuliah semester depan secara real-time (DOM Manipulation).
IPK Target Simulator: Kalkulator matematis real-time yang terkunci pada SKS yang sudah diambil (status: Taken).
The Algorithm Redline: Visualizer algoritma sorting (Bubble, Selection, Quick) dengan simulasi RPM gauge (Big O Notation).
The Pit Stop: Debug Terminal: Interaktif perbaikan bug kode JavaScript menggunakan antarmuka terminal.
Enterprise Media Hub: Pemutar video lokal (<video>) dan audio lokal (<audio>), serta materi pembelajaran eksternal dari YouTube.
The Knowledge Base: Perpustakaan referensi buku/dokumentasi interaktif.
The Architect's Gallery: Galeri visual behind-the-scenes dengan efek hover grayscale-to-color.
The Enterprise Team: Halaman kontributor dengan struktur Vertical Flowchart dan kartu 3D Flip berisi data dosen & anggota tim.

🛠️ Teknologi yang Digunakan
HTML5 Semantik: Paragraf, heading, text formatting (<b>, <i>, <u>), link, image, table, list, form (<textarea>, <select>, <input>), video, audio.
Custom CSS3: Tanpa framework eksternal. Menggunakan CSS Variables, Flexbox, CSS Grid, 3D Transforms (rotateY), IntersectionObserver, dan Cinematic Filters.
Vanilla JavaScript (ES6): Array of Objects (In-Memory Database), Math Randomization, DOM Manipulation, Event Listeners, Async/Await (untuk visualisasi algoritma).
